DESCRIPTION:
  This directory contains the most recent version of GFZ RL06 Level-3 Terrestrial Water Storage Products.
  Current most recent version is: 0006

  The following files are available:

  ./GRAVIS-3_GFZOP_0600_TWS_GRID_GFZ_0006.nc   => Terrestrial Water Storage Products in NetCDF format

  ./GravIS_TWS_Technical_Note.pdf   => Technical Note describing the processing scheme and product details

  ./old_versions/   => subdirectory where previously released versions of GFZ RL06 Terrestrial Water Storage Products are archived
  ./GFZ_GRAVIS_06_L3_TWS_changelog.pdf   => document containing the version history of GFZ RL06 Terrestrial Water Storage Products

CITATION:
  When using this version of GravIS GFZ RL06 Level-3 Terrestrial Water Storage Products, please use the following citation:

  Boergens, E., Dobslaw, H., Dill, R. (2019):
  GFZ GravIS RL06 Continental Water Storage Anomalies.
  V. 0006. GFZ Data Services. https://doi.org/10.5880/GFZ.GRAVIS_06_L3_TWS
