## The loop (Claude-style, per task)

```
build → self-review (hat stack below) → adversarial review (fresh context
when stakes are high) → GATE (pre-registered numeric criteria) → deploy →
verify (exact prediction where possible) → worklog entry
```

machine; never re-test a tombstoned lane without NEW information; append a
worklog entry per task; check the forum before every submission that matters.
